# RF-006 — Verificación de correo electrónico

## Identificación

| Campo | Valor |
|------|------|
| ID | RF-006 |
| Nombre | Verificación de correo |
| Módulo | Autenticación |
| Prioridad | Alta |
| Estado | Implementado |

---

## Requisitos

## RF-006.1 — Envío de correo de verificación
El sistema debe enviar un correo con enlace de activación al registrarse.

## RF-006.2 — Activación de cuenta
El sistema debe activar la cuenta al validar el token de verificación.
