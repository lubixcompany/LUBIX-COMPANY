# RF-014 — Cambiar contraseña

## Identificación

| Campo | Valor |
|------|------|
| ID | RF-014 |
| Nombre | Cambiar contraseña |
| Módulo | Perfil |
| Prioridad | Alta |
| Estado | Implementado |

---

## Requisitos

## RF-014.1 — Validación de contraseña actual
El sistema debe verificar la contraseña actual antes de permitir el cambio.

## RF-014.2 — Actualización segura
La nueva contraseña debe ser almacenada con hashing seguro.
