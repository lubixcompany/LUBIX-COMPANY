## Criterios de aceptación

### CA-008.1 — Contraseña actual obligatoria
Debe solicitar la contraseña actual.

### CA-008.2 — Nueva contraseña obligatoria
Debe ingresar nueva contraseña.

### CA-008.3 — Confirmación obligatoria
Debe confirmar la nueva contraseña.

### CA-008.4 — Validación de seguridad
La contraseña debe cumplir requisitos mínimos.

### CA-008.5 — Cambio exitoso
La contraseña debe actualizarse correctamente.
