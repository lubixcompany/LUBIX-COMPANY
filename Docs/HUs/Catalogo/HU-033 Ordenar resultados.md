# HU-033 — Ver panel de vendedor

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-033 |
| Título | Ver panel de vendedor |
| Módulo | Vendedor |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-033 |

---

## Historia

Como vendedor de Lubix, quiero ver un panel de control, para gestionar mis productos, ventas y estadísticas.

---

## Criterios de aceptación

### CA-033.1 — Dashboard disponible
Debe existir un panel exclusivo para vendedores.

### CA-033.2 — Resumen de ventas
Debe mostrar ventas totales.

### CA-033.3 — Acceso a módulos
Debe permitir acceso a productos y pedidos.
