# HU-053 — Pagar con transferencia bancaria

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-053 |
| Título | Pagar con transferencia bancaria |
| Módulo | Pagos |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-053 |

---

## Historia

Como usuario de Lubix, quiero pagar mediante transferencia bancaria, para tener una alternativa de pago.

---

## Criterios de aceptación

### CA-053.1 — Datos bancarios
Debe mostrar información de cuenta bancaria.

### CA-053.2 — Confirmación de transferencia
Debe permitir confirmar pago manual.

### CA-053.3 — Estado pendiente
El pago queda en estado "pendiente" hasta verificación.
