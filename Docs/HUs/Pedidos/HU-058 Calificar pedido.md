# HU-058 — Guardar método de pago

## Identificación

| Campo | Valor |
|---------|---------|

| Título | Guardar método de pago |
| Módulo | Pagos |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-058 |

---

## Historia

Como usuario de Lubix, quiero guardar mis métodos de pago, para agilizar futuras compras.

---

## Criterios de aceptación

### CA-058.1 — Guardado seguro
Debe almacenar métodos de pago de forma segura.

### CA-058.2 — Selección rápida
Debe permitir usar métodos guardados.

### CA-058.3 — Eliminación
Debe permitir eliminar métodos guardados.
