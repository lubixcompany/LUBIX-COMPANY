# HU-060 — Registro de transacciones

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-060 |
| Título | Registro de transacciones |
| Módulo | Pagos |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-060 |

---

## Historia

Como sistema de Lubix, quiero registrar todas las transacciones, para mantener un historial completo de pagos.

---

## Criterios de aceptación

### CA-060.1 — Registro automático
Cada pago debe registrarse automáticamente.

### CA-060.2 — Información completa
Debe guardar monto, usuario y fecha.

### CA-060.3 — Acceso administrativo
Solo administradores pueden ver todos los registros.
