# HU-043 — Modificar cantidades del carrito

| Campo | Valor |

| Título | Modificar cantidades del carrito |

---

## Historia

Como usuario de Lubix, quiero modificar las cantidades de productos en el carrito, para ajustar mi compra.

---

## Criterios de aceptación

### CA-043.1 — Campo editable
Debe permitir cambiar cantidad.

### CA-043.2 — Validación
No se permiten valores negativos o cero.

### CA-043.3 — Actualización automática
El total debe recalcularse.
