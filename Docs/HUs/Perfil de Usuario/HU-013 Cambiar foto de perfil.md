# HU-013 — Ordenar productos

## Identificación

| Campo | Valor |
|---------|---------|

| Título | Ordenar productos |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-013 |

---

## Historia

Como usuario de Lubix, quiero ordenar los productos según diferentes criterios, para ver primero los más relevantes.

---

## Criterios de aceptación

### CA-013.1 — Opciones de orden
Debe permitir ordenar por precio, popularidad o fecha.

### CA-013.2 — Orden ascendente y descendente
Debe permitir ambos tipos de orden.

### CA-013.3 — Actualización inmediata
Los resultados deben actualizarse al cambiar el orden.
