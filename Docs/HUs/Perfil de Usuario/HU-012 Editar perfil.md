# HU-012 — Filtrar productos por categoría

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-012 |
| Título | Filtrar productos por categoría |
| Módulo | Catálogo |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-012 |

---

## Historia

Como usuario de Lubix, quiero filtrar productos por categoría, para encontrar más fácilmente lo que estoy buscando.

---

## Criterios de aceptación

### CA-012.1 — Lista de categorías
Deben mostrarse categorías disponibles.

### CA-012.2 — Filtro funcional
Al seleccionar una categoría, se deben filtrar los productos.

### CA-012.3 — Actualización de resultados
Los productos deben actualizarse automáticamente.

### CA-012.4 — Mensaje sin resultados
Debe mostrarse mensaje si no hay productos en la categoría.
