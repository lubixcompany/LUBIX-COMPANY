# HU-021 — Crear producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-021 |
| Título | Crear producto |
| Módulo | Productos |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-021 |

---

## Historia

Como vendedor de Lubix, quiero crear un producto, para publicarlo y ofrecerlo a los usuarios en la plataforma.

---

## Criterios de aceptación

### CA-021.1 — Formulario de creación
Debe existir un formulario con nombre, precio, descripción e imagen.

### CA-021.2 — Validación de campos
No se permiten campos vacíos.

### CA-021.3 — Guardado exitoso
El producto debe guardarse correctamente.
