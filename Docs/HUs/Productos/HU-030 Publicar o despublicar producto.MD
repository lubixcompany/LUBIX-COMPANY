# HU-030 — Responder preguntas de clientes

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-030 |
| Título | Responder preguntas de clientes |
| Módulo | Vendedor |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-030 |

---

## Historia

Como vendedor de Lubix, quiero responder preguntas de clientes, para mejorar la atención y confianza en mis productos.

---

## Criterios de aceptación

### CA-030.1 — Sistema de preguntas
Debe existir sección de preguntas.

### CA-030.2 — Respuesta del vendedor
Debe permitir responder directamente.

### CA-030.3 — Visualización pública
Las respuestas deben ser visibles para otros usuarios.
