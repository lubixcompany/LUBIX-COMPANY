# RF-017 — Configurar preferencias

## Identificación

| Campo | Valor |
|---------|---------|

| Nombre | Configurar preferencias |
| Módulo | Perfil de Usuario |
| Prioridad | Baja |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir configurar preferencias del usuario como idioma, notificaciones y configuración visual.

---

## Proceso

- Usuario modifica preferencias.
- Se almacenan en tabla user_preferences.

---

## Reglas de negocio

RN-001: Las preferencias deben persistir por usuario.
