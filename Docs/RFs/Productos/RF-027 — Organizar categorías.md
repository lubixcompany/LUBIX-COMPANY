# RF-027 — Organizar categorías

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-027 |
| Nombre | Organizar categorías |
| Módulo | Productos |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir asignar productos a categorías.

---

## Proceso

- Vendedor selecciona categoría.
- Se asigna producto.
- Se actualiza estructura del catálogo.

---

## Reglas de negocio

RN-001: Cada producto debe tener al menos una categoría.
