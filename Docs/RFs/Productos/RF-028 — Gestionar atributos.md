# RF-028 — Gestionar atributos de producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-028 |
| Nombre | Gestionar atributos de producto |
| Módulo | Productos |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir definir atributos como color, talla o material.

---

## Proceso

- Usuario define atributos.
- Se asocian al producto.
- Se guardan variantes.

---

## Reglas de negocio

RN-001: Un producto puede tener múltiples atributos.
