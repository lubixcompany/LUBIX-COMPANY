# RF-009 — Autenticación en dos pasos

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-009 |
| Nombre | 2FA |
| Módulo | Autenticación |
| Prioridad | Media |
| Estado | Pendiente |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir autenticación en dos pasos mediante código.

---

## Proceso

- Usuario ingresa credenciales.
- Sistema envía código.
- Usuario valida código.

---

## Reglas de negocio

RN-001: Código expira en minutos.
