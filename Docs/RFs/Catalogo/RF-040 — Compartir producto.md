# RF-040 — Compartir producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-040 |
| Nombre | Compartir producto |
| Módulo | Catálogo |
| Prioridad | Baja |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir compartir productos mediante enlaces o redes sociales.

---

## Proceso

- Usuario selecciona compartir.
- Se genera URL del producto.
- Se habilitan opciones de compartir.

---

## Reglas de negocio

RN-001: El enlace debe ser público solo si el producto está publicado.
