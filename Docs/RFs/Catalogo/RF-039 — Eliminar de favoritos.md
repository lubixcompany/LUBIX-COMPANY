# RF-039 — Eliminar de favoritos

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-039 |
| Nombre | Eliminar de favoritos |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir quitar productos de la lista de favoritos del usuario.

---

## Proceso

- Usuario selecciona eliminar.
- Se borra relación en base de datos.

---

## Reglas de negocio

RN-001: Solo afecta al usuario actual.
