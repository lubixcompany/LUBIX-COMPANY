# RF-038 — Agregar a favoritos

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-038 |
| Nombre | Agregar a favoritos |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir al usuario guardar productos como favoritos.

---

## Proceso

- Usuario selecciona “favorito”.
- Se guarda relación usuario-producto.
- Se actualiza lista de favoritos.

---

## Reglas de negocio

RN-001: Un usuario puede tener múltiples favoritos.
