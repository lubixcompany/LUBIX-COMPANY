# RF-036 — Ver productos destacados

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-036 |
| Nombre | Ver productos destacados |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe mostrar productos destacados seleccionados por el sistema o administrador.

---

## Proceso

- Se consultan productos con flag “featured”.
- Se muestran en sección principal.

---

## Reglas de negocio

RN-001: Solo administradores pueden marcar productos destacados.
