# RF-029 — Duplicar producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-029 |
| Nombre | Duplicar producto |
| Módulo | Productos |
| Prioridad | Baja |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir duplicar un producto existente para facilitar creación rápida.

---

## Proceso

- Usuario selecciona producto.
- Se copia información base.
- Se crea nuevo producto con nuevo ID.

---

## Reglas de negocio

RN-001: El producto duplicado debe tener SKU único.
