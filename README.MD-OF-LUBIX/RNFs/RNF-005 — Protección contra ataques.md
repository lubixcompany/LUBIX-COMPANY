# RF-005 — Cerrar sesión

## Identificación

| Campo | Valor |
|------|------|
| ID | RF-005 |
| Nombre | Cerrar sesión |
| Módulo | Autenticación |
| Prioridad | Media |
| Estado | Implementado |

---

## Requisitos

## RF-005.1 — Logout del sistema
El sistema debe permitir cerrar la sesión del usuario actual.

## RF-005.2 — Invalidación de token
El token JWT debe ser invalidado o eliminado del almacenamiento local.
