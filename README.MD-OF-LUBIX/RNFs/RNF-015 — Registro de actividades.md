# RF-015 — Gestionar direcciones

## Identificación

| Campo | Valor |
|------|------|
| ID | RF-015 |
| Nombre | Direcciones |
| Módulo | Perfil |
| Prioridad | Media |
| Estado | Implementado |

---

## Requisitos

## RF-015.1 — Agregar dirección
El sistema debe permitir agregar nuevas direcciones de usuario.

## RF-015.2 — Editar dirección
El sistema debe permitir modificar direcciones existentes.

## RF-015.3 — Eliminar dirección
El sistema debe permitir eliminar direcciones registradas.
