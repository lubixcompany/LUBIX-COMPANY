# HU-024 — Cambiar precio de producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-024 |
| Título | Cambiar precio de producto |
| Módulo | Productos |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-024 |

---

## Historia

Como vendedor de Lubix, quiero cambiar el precio de mis productos, para ajustarlos según el mercado.

---

## Criterios de aceptación

### CA-024.1 — Campo de precio editable
Debe permitir modificar el precio.

### CA-024.2 — Validación numérica
El precio debe ser un número válido.

### CA-024.3 — Guardado exitoso
El cambio debe reflejarse inmediatamente.
