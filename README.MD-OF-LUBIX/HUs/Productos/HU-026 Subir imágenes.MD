# HU-026 — Subir imágenes de producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-026 |
| Título | Subir imágenes de producto |
| Módulo | Productos |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-026 |

---

## Historia

Como vendedor de Lubix, quiero subir imágenes de mis productos, para que los usuarios puedan verlos claramente.

---

## Criterios de aceptación

### CA-026.1 — Carga de imágenes
Debe permitir subir imágenes.

### CA-026.2 — Formatos válidos
Solo se permiten formatos JPG y PNG.

### CA-026.3 — Vista previa
Debe mostrar vista previa antes de guardar.
