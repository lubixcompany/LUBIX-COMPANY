## Historia

Como vendedor de Lubix, quiero gestionar el inventario de mis productos, para controlar las cantidades disponibles.

---

## Criterios de aceptación

### CA-025.1 — Control de stock
Debe permitir modificar cantidades disponibles.

### CA-025.2 — Stock mínimo
Debe alertar cuando el stock sea bajo.

### CA-025.3 — Actualización en tiempo real
El stock debe actualizarse automáticamente.
