# HU-028 — Ver estadísticas de ventas

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-028 |
| Título | Ver estadísticas de ventas |
| Módulo | Vendedor |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-028 |

---

## Historia

Como vendedor de Lubix, quiero ver estadísticas de mis ventas, para analizar el rendimiento de mis productos.

---

## Criterios de aceptación

### CA-028.1 — Gráficos de ventas
Debe mostrar gráficos de ventas.

### CA-028.2 — Periodos de tiempo
Debe permitir filtrar por fechas.

### CA-028.3 — Datos actualizados
Las estadísticas deben actualizarse automáticamente.
