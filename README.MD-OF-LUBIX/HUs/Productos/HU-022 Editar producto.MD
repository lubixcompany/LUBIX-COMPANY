# HU-022 — Editar producto

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-022 |
| Título | Editar producto |
| Módulo | Productos |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-022 |

---

## Historia

Como vendedor de Lubix, quiero editar mis productos, para mantener la información actualizada.

---

## Criterios de aceptación

### CA-022.1 — Acceso a edición
Debe permitir editar productos existentes.

### CA-022.2 — Validación de datos
No se permiten campos inválidos.

### CA-022.3 — Guardado correcto
Los cambios deben guardarse correctamente.
