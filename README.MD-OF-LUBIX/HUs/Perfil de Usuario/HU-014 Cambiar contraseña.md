---

## Historia

Como usuario de Lubix, quiero ver el detalle de un producto, para conocer toda su información antes de comprarlo.

---

## Criterios de aceptación

### CA-014.1 — Información completa
Debe mostrar descripción, precio, imágenes y stock.

### CA-014.2 — Imágenes ampliables
Las imágenes deben poder ampliarse.

### CA-014.3 — Botón de compra
Debe existir opción para agregar al carrito.
