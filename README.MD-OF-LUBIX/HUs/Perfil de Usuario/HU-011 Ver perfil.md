# HU-011 — Ver catálogo de productos destacados

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-011 |
| Título | Ver productos destacados |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-011 |

---

## Historia

Como usuario de Lubix, quiero ver los productos destacados, para encontrar fácilmente los artículos más relevantes o populares.

---

## Criterios de aceptación

### CA-011.1 — Sección de destacados
Debe existir una sección de productos destacados.

### CA-011.2 — Productos visibles
Deben mostrarse productos con mayor relevancia o popularidad.

### CA-011.3 — Información básica
Cada producto debe mostrar nombre, imagen y precio.

### CA-011.4 — Actualización dinámica
Los productos destacados deben actualizarse automáticamente.
