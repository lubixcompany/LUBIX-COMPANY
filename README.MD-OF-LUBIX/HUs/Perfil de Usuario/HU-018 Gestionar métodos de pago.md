# HU-018 — Realizar compra

## Identificación

| Campo | Valor |
|---------|---------|

| Título | Realizar compra |
| Módulo | Pedidos |
| Prioridad | Alta |
| Estado | Pendiente |

---

## Historia

Como usuario de Lubix, quiero realizar una compra, para adquirir los productos seleccionados en el carrito.

---

## Criterios de aceptación

### CA-018.1 — Resumen de compra
Debe mostrarse resumen antes de pagar.

### CA-018.2 — Confirmación de compra
El usuario debe confirmar la orden.

### CA-018.3 — Generación de pedido
El sistema debe generar el pedido automáticamente.
