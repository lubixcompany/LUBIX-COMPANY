# HU-051 — Seleccionar método de pago

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-051 |
| Título | Seleccionar método de pago |
| Módulo | Pagos |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-051 |

---

## Historia

Como usuario de Lubix, quiero seleccionar un método de pago, para poder completar mi compra de forma segura.

---

## Criterios de aceptación

### CA-051.1 — Lista de métodos
Debe mostrar métodos de pago disponibles.

### CA-051.2 — Selección válida
Debe permitir elegir solo un método.

### CA-051.3 — Confirmación
Debe confirmar el método seleccionado.
