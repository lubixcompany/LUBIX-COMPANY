# HU-009 — Visualizar catálogo de productos

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-009 |
| Título | Visualizar catálogo de productos |
| Módulo | Catálogo |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-009 |

---

## Historia

Como usuario de Lubix, quiero ver el catálogo de productos disponibles, para explorar lo que ofrece la plataforma.

---

## Criterios de aceptación

### CA-009.1 — Mostrar productos
Se deben listar productos disponibles.

### CA-009.2 — Imágenes visibles
Cada producto debe mostrar su imagen.

### CA-009.3 — Información básica
Debe mostrar nombre y precio.

### CA-009.4 — Paginación
El catálogo debe paginar resultados.

### CA-009.5 — Carga eficiente
Debe cargar sin demoras excesivas.
