# HU-010 — Buscar productos

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-010 |
| Título | Buscar productos |
| Módulo | Catálogo |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-010 |

---

## Historia

Como usuario de Lubix, quiero buscar productos, para encontrar rápidamente lo que necesito dentro del catálogo.

---

## Criterios de aceptación

### CA-010.1 — Barra de búsqueda
Debe existir una barra visible.

### CA-010.2 — Búsqueda por nombre
Debe permitir buscar por nombre del producto.

### CA-010.3 — Búsqueda por categoría
Debe permitir filtrar por categoría.

### CA-010.4 — Resultados en tiempo real
Debe actualizar resultados dinámicamente.

### CA-010.5 — Sin resultados
Debe mostrar mensaje si no hay coincidencias.
