## Criterios de aceptación

cuando modifico el nombre,
entonces debe guardarse correctamente.

### CA-007.2 — Edición de datos
Se pueden actualizar datos como nombre y teléfono.

### CA-007.3 — Validación de datos
No se permiten campos vacíos inválidos.

### CA-007.4 — Guardado exitoso
Los cambios deben confirmarse correctamente.
