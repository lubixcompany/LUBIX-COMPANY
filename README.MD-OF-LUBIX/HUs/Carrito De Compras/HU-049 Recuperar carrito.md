# HU-049 — Cancelar pedido

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-049 |
| Título | Cancelar pedido |
| Módulo | Pedidos |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-049 |

---

## Historia

Como usuario de Lubix, quiero cancelar un pedido, para evitar compras realizadas por error.

---

## Criterios de aceptación

### CA-049.1 — Botón cancelar
Debe existir opción de cancelación.

### CA-049.2 — Restricción por estado
Solo pedidos pendientes pueden cancelarse.

### CA-049.3 — Confirmación
Debe solicitar confirmación.
