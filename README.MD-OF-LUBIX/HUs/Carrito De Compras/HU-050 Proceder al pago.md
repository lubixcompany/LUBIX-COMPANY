## Historia

Como usuario de Lubix, quiero confirmar que recibí mi pedido, para finalizar el proceso de compra.

---

## Criterios de aceptación

### CA-050.1 — Botón confirmar recepción
Debe existir opción para confirmar entrega.

### CA-050.2 — Cambio de estado
El pedido debe cambiar a "Entregado".

### CA-050.3 — Confirmación final
Debe mostrarse mensaje de éxito.
