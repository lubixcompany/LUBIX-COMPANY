# HU-035 — Gestionar promociones

## Identificación

| Campo | Valor |

| Título | Gestionar promociones |
| Módulo | Vendedor |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | RF-035 |

---

## Historia

Como vendedor de Lubix, quiero crear promociones en mis productos, para aumentar las ventas.

---

## Criterios de aceptación

### CA-035.1 — Crear promoción
Debe permitir asignar descuentos.

### CA-035.2 — Fecha de vigencia
Debe permitir definir fechas de inicio y fin.

### CA-035.3 — Aplicación automática
La promoción debe aplicarse al precio.
