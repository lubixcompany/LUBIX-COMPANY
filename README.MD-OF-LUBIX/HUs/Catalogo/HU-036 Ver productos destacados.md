## Historia

Como administrador de Lubix, quiero aprobar productos publicados por vendedores, para asegurar la calidad del catálogo.

---

## Criterios de aceptación

### CA-036.1 — Lista de productos
Debe mostrar productos pendientes de aprobación.

### CA-036.2 — Aprobar producto
Debe permitir aprobar productos.

### CA-036.3 — Rechazar producto
Debe permitir rechazar productos.
