# HU-031 — Registrar tienda como vendedor

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-031 |
| Título | Registrar tienda |
| Módulo | Vendedor |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-031 |

---

## Historia

Como usuario vendedor de Lubix, quiero registrar una tienda, para poder publicar y gestionar mis productos dentro de la plataforma.

---

## Criterios de aceptación

### CA-031.1 — Formulario de tienda
Debe existir formulario con nombre de tienda y descripción.

### CA-031.2 — Validación de datos
No se permiten campos vacíos.

### CA-031.3 — Creación exitosa
La tienda debe registrarse correctamente.
